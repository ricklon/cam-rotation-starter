# CAD

The design lives in Autodesk Fusion, as the document *Cam Rotation N20* in MovementStudy › Cam Rotation Tool, copied from the MG90S drive's *Cam Rotation Starter*. No release is tagged yet; the snapshots in `step/` match Fusion version 39 of that document (rev C: perfboard with the PD board on the mount's −Y face, Super Mini, electronics cover, the Hall encoder motor with its 6-wire cable soldered to the perfboard; all wiring 30 AWG stranded except the motor cable, the knob at J10–J12 wired 3V3 → pot → GPIO3 with its wiper on GPIO4, and C3, the hold-up capacitor). Version 23 included the owner's own earlier unsaved edits as well as rev C; version 24 had the perfboard on an enlarged flange ear. Version 26 also saved edits that were open but unsaved in the document before the 30 AWG and knob changes; version 27 added C3 and the motor's factory leads, with the wire clamp resized for them. Version 28 swapped U1's pads to match the owner's PD board (− outer, + inner) and rerouted W1 and W2 so they don't cross. Version 29 stood C1 on the perfboard (+ to C7, − to B4, top through a 9 mm hole in the cover), and removed its seat in the mount and the wires L1 and L2. Version 30 dropped the direction switch SW1 and the J3 panel connector (and its holder in the pod): the button is wired straight to the perfboard by W6 and W11. Version 31 enlarged the mount's bushing bore and gave the N20 its own bushings (see below). Version 33 (32 was an intermediate save with RV1 and C3 misplaced) refitted the electronics cover to the board as built (RV1 standing with its shaft parallel to the board, C3 standing), from user parameters that `fusion/cover_rv1.py` turns into the parts and the cover; version 34 used the measured shaft height, bushing reach and C3 size. Version 35 moved the bushing's flange recess to the mount's wall face (see below); version 36 only rewords the `bush_od` comment. Version 38 adds `N20_Encoder`, the Hall encoder on the back of the 1:150 encoder gearmotor, and cuts the cartridge's snap hooks off 24.8 mm below the gearbox face so the encoder board clears them (see [Encoder motor](../README.md#encoder-motor-2026-11-08)). Version 39 routes the encoder motor's cable (W24–W29, from the encoder's plug through the cover's notch to the perfboard), adds the links W30 and W31, stands C2 on the perfboard at I2/I3 and hides the plain N20's 2-pin J4 header, all from `fusion/wires.py`; W14 and W15 are no longer drawn. When this drive is tagged `vMAJOR.MINOR-n20`, record here which Fusion version the tag matches. This folder holds copies you can open without Fusion, the print files, and the scripts used to build and document the model.

## Opening the parametric model

Import `step/cam-rotation-n20.f3d` into Fusion (File → Open → Open from my computer). It keeps the MG90S drive's user parameters (see [the MG90S CAD notes](../../mg90s/cad/README.md#opening-the-parametric-model)); the parameters added for the N20 are listed under [Fusion design](../README.md#fusion-design) in this drive's README.

## Scripts

**`fusion/wires.py`** rebuilds every wire in the model's `Wiring` component from a list of waypoints, with colours and sizes from the [wire list](../docs/wiring.md). From rev C it includes the perfboard's underside links, placed by column and row with its `hx`/`hy` helpers. Run it in Fusion's script runner, or through the Fusion MCP server with `exec(open('drives/n20/cad/fusion/wires.py').read())`.

**`fusion/shots.py`** renders this drive's `docs/images`. It reuses the MG90S drive's `photo.py`, so set `CAM_REPO` to your checkout (it sets `CAM_DRIVE` itself), exec it with *Cam Rotation N20* active, and call `run_shots()`.

**`fusion/encoder_motor.py`** rebuilds the `N20_Encoder` component (board, magnet cap, 6-pin plug and a keep-out for the wires) from measured constants at the top of the file, so the encoder can be checked against the cartridge, mount and perfboard. Run it the same way as `wires.py`.

**`fusion/orient_stl.py`** turns STLs exported from Fusion into `cad/stl/raw/` into print-ready files and rewrites the parts table in `stl/README.md`, as in the MG90S drive. Parts with no file in `raw/` keep their existing row, so you can re-export only the parts that changed.

**Bushings (version 31; shared with the MG90S drive again from its version 50):** the mount's top-plate bore is Ø29.2 mm so the assembled 5/8 clamp, with its M3 cap heads (14.3 mm swept), drops through from above. The N20 bushings are Ø29.0 mm outside with a Ø34 mm double-D flange (flats 28.8 mm apart, parallel to the side walls), The MG90S drive got the same bore and bushings on 2026-11-03 (*Cam Rotation Starter* version 50), so the bushings are a shared part again: change both documents together, per `AGENTS.md`. Dowel bores unchanged. From version 35 (MG90S version 51) the flange sits in a 1.6 mm recess in the mount's wall face (`bush_recess_depth`) instead of under the top plate: the bushing goes in from the wall side and the box wall retains it, so nothing has to slide in under the plate past the clamp. Box wall hole: the dowel size is enough, because the dowel and clamp go through the mount, then the bushing, before the mount is screwed to the box.
