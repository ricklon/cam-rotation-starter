# CAD

The design lives in Autodesk Fusion, as the document *Cam Rotation N20* in MovementStudy › Cam Rotation Tool, copied from the MG90S drive's *Cam Rotation Starter*. No release is tagged yet; the snapshots in `step/` match Fusion version 32 of that document (rev C: perfboard with the PD board on the mount's −Y face, Super Mini, electronics cover, motor wire clamp; all wiring 30 AWG stranded except the motor's own leads, the knob at J10–J12 wired 3V3 → pot → GPIO3 with its wiper on GPIO4, and C3, the hold-up capacitor). Version 23 included the owner's own earlier unsaved edits as well as rev C; version 24 had the perfboard on an enlarged flange ear. Version 26 also saved edits that were open but unsaved in the document before the 30 AWG and knob changes; version 27 added C3 and the motor's factory leads, with the wire clamp resized for them. Version 28 swapped U1's pads to match the owner's PD board (− outer, + inner) and rerouted W1 and W2 so they don't cross. Version 29 stood C1 on the perfboard (+ to C7, − to B4, top through a 9 mm hole in the cover), and removed its seat in the mount and the wires L1 and L2. Version 30 dropped the direction switch SW1 and the J3 panel connector (and its holder in the pod): the button is wired straight to the perfboard by W6 and W11. Version 31 enlarged the mount's bushing bore and gave the N20 its own bushings (see below). Version 32 refitted the electronics cover to the board as built (RV1 standing with its shaft parallel to the board, C3 standing), from user parameters that `fusion/cover_rv1.py` turns into the parts and the cover. When this drive is tagged `vMAJOR.MINOR-n20`, record here which Fusion version the tag matches. This folder holds copies you can open without Fusion, the print files, and the scripts used to build and document the model.

## Opening the parametric model

Import `step/cam-rotation-n20.f3d` into Fusion (File → Open → Open from my computer). It keeps the MG90S drive's user parameters (see [the MG90S CAD notes](../../mg90s/cad/README.md#opening-the-parametric-model)); the parameters added for the N20 are listed under [Fusion design](../README.md#fusion-design) in this drive's README.

## Scripts

**`fusion/wires.py`** rebuilds every wire in the model's `Wiring` component from a list of waypoints, with colours and sizes from the [wire list](../docs/wiring.md). From rev C it includes the perfboard's underside links, placed by column and row with its `hx`/`hy` helpers. Run it in Fusion's script runner, or through the Fusion MCP server with `exec(open('drives/n20/cad/fusion/wires.py').read())`.

**`fusion/shots.py`** renders this drive's `docs/images`. It reuses the MG90S drive's `photo.py`, so set `CAM_REPO` to your checkout (it sets `CAM_DRIVE` itself), exec it with *Cam Rotation N20* active, and call `run_shots()`.

**`fusion/orient_stl.py`** turns STLs exported from Fusion into `cad/stl/raw/` into print-ready files and rewrites the parts table in `stl/README.md`, as in the MG90S drive. Parts with no file in `raw/` keep their existing row, so you can re-export only the parts that changed.

**N20-only bushings (version 31):** the mount's top-plate bore is Ø29.2 mm so the assembled 5/8 clamp, with its M3 cap heads (14.3 mm swept), drops through from above. The N20 bushings are Ø29.0 mm outside with a Ø34 mm double-D flange (flats 28.8 mm apart, parallel to the side walls), retained from below. They **differ from the MG90S bushings on purpose: don't sync them back.** Dowel bores unchanged. Box wall hole: Ø20 mm is enough if the dowel and clamp go through the mount before it's screwed to the box; to push them in from inside the box with the drive already mounted, the box hole needs ≥ Ø29.2 mm (a 30 mm bit).
