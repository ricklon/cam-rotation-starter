# AGENTS.md: notes for coding agents

Read README.md first. This repository is open hardware: a 3D-printed servo drive for cam-driven story boxes, its ESP32-C6 firmware and web app, and the documentation to build it.

## Where things are

| Path | What | Notes |
|---|---|---|
| `firmware/` | ESP-IDF firmware + Vite web app | Has its own `AGENTS.md`; read it before touching firmware. Apache-2.0. |
| `cad/step/` | `.step` and `.f3d` exports of the Fusion design | The live design is in the owner's Fusion account; these are snapshots. Re-export after design changes. |
| `cad/stl/` | Print-ready STLs + `README.md` | Generated by `cad/fusion/orient_stl.py` from `cad/stl/raw/` exports; the parts table in the README is rewritten between `<!-- parts -->` markers. |
| `cad/fusion/` | Fusion scripts | `wires.py` rebuilds the `Wiring` component from waypoint lists; `photo.py`/`steps.py` render `docs/images`. Run inside Fusion (or via the Fusion MCP server with `exec(open(...).read())`). |
| `docs/` | parts, wiring, cut list, assembly | Markdown + CSV. Wire IDs (W1–W11, L1–L3, J1–J2, R1) must match `cad/fusion/wires.py` body names and `docs/cut-list.csv`. |
| `hardware/` | fastener table + McMaster STEP files | |
| `classroom/` | teaching notes + example stories | Story JSON must match the firmware's format (see `firmware/README.md`). |

## Conventions

- Documentation is Markdown, data is CSV or JSON. No Word, Excel or PowerPoint files.
- Units: millimetres in CAD and scripts; inches only where a part is sold in inches (dowels, wood screws), with mm alongside.
- Images in `docs/images/` are rendered from the model; when the model changes, re-render rather than editing images, and keep alt text accurate to what the image shows.
- Keep every part's swept radius around the servo axis under 13.5 mm: the mount's side walls are 14.75 mm from the axis.
- The pod's interior is 23 × 34 × 22 mm; check clearances (Fusion interference or boolean intersection) after moving anything inside it.
- In Fusion, moving occurrences in a parametric design needs `design.snapshots.add()` afterwards, or a later parameter change resets their positions.
